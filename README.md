## 🧾 Description des fonctionnalités

### ✅ 1. Formulaire HTML5
La page contient plusieurs champs HTML5 :
- Texte
- Email
- Mot de passe
- Nombre
- Téléphone
- URL
- Date et heure
- Couleur
- Fichier
- Radio (genre)
- Checkbox (langages)
- Liste déroulante (select)
- Zone de texte (textarea)

---

### ⚙️ 2. Fonction JavaScript : Calcul de taxe
- L'utilisateur entre un prix
- Le programme calcule une taxe de **17%**
- Le résultat affiche :
  - La taxe
  - Le prix total

📌 Exemple :

Prix = 100
Taxe = 17
Total = 117


---

### 📅 3. Fonction JavaScript : Date du jour
- Affiche la date actuelle
- Utilise l'objet `Date` de JavaScript

---

### 🔍 4. Fonction JavaScript : Recherche dans un tableau
- Vérifie si un nombre existe dans un tableau
- Utilise la méthode `includes()`
- Retourne :
  - ✅ true (existe)
  - ❌ false (n'existe pas)

📌 Exemple :

Tableau = [1, 2, 3, 4, 5, 10, 20]
Recherche = 10 → true
Recherche = 99 → false
